# 8bercue Beta 1

Android eSIM 管理工具；独立项目，非 5ber 官方产品。发布者 sid，支持与隐私联系 support@sidnvy.com。

这是直接分发的 **Beta 预发布版**，不是稳定版。安装包内版本为 `0.18.0-rc1`（versionCode 22）；Beta 1 是分发渠道名称。沿用已完成实机验证的正式签名 APK，未重新编译或更换签名。

## 已验证范围

- Moto Edge 70 与此次授权 5ber 卡：正常应用界面的改名、恢复昵称、禁用、启用；操作后独立读卡确认最终库存恢复一致。
- 正式签名迁移、非调试 Release、构建/lint、离线回归；源码归档独立构建，两次 APK/AAB 字节重现，原生组件重编译一致。
- 模拟器调用隔离、四组字体/方向/主题组合，以及合成 worker 进程死亡后的日志恢复与禁止自动重放。

## 已知限制

- 本版成功下载 → 通知 → 删除的完整实机流程尚未验证。相关功能作为实验功能提供；只使用可消耗激活码和可删除的测试 Profile。
- 其他手机、其他卡及新的卡身份组合尚未完成兼容性验收。支持代码使用动态发现，已测范围不等于所有设备兼容承诺。
- ARM64 16KB 环境仅做静态对齐检查，未完成实际运行测试。
- 卡内“已启用”不代表已注册网络；数据、通话和短信可用性不在本次通过范围内。
- 大字体/旋转测试不等于 TalkBack 完整验收；合成崩溃测试不等于真实调制解调器故障测试。

首次试用建议采用备用设备和测试卡。操作前核对目标 Profile；禁用可能中断连接，删除可能无法恢复。出现未知结果时停止写操作，先执行应用的恢复核验；不要反复提交激活码或删除安全日志来重试。

## 安装与连接

下载正式签名 APK；源码、许可证与隐私说明随本 Release 提供。Android 包配置要求 API 28+、ARM64，具体兼容性仍受上述范围限制。

同签名安装可使用 `adb -s YOUR_SERIAL install -r 8bercue-0.18.0-rc1.apk`。若已有不同签名的测试版，不要直接卸载或清除数据来绕过失败：先确认无未决事务、备份应用和 Shell 安全记录，再审阅迁移。卸载应用不会自动删除卡内 Profile，也不会自动清除 Shell 安全记录。

打开应用选择“Connect using computer”，在已授权的 ADB 连接上运行：

```sh
python3 bootstrap_companion.py --serial YOUR_SERIAL --adb /path/to/adb
```

已有无线 ADB 连接需附加 `--allow-existing-wireless`。应用更新或手机重启后需重新连接。
